# ⚡ Productive.app — Hitos Diarios

Una aplicación web de productividad premium, interactiva y totalmente responsive (optimizada para dispositivos móviles y escritorio), diseñada para ayudarte a trackear tus hábitos y gestionar tus tareas diarias de manera segura.

✨ **[¡Ver la Aplicación Online!](https://santri2019-droid.github.io/Productividad-app/)**

---

## 🚀 Características Premium

*   **📱 Diseño Móvil Primero (Android 360x800px) & Desktop**: Experiencia fluida con barra de navegación inferior en móviles y barra lateral en escritorio.
*   **📊 Rastreador de Hitos y Reportes**: Tabla interactiva con scroll horizontal, selector de estados y generación de reportes mensuales en formato descargable `.txt`.
*   **✅ Gestor de Tareas Avanzado**: Incorpora vista "Mi Día", filtros inteligentes, generación de reportes de tareas, buscador en tiempo real y notificaciones diarias (vía Web Notification API y aviso visual in-app).
*   **📈 Evolución Mensual**: Vista interactiva en formato acordeón que agrupa el historial de tus metas mes a mes, facilitando el análisis a largo plazo de tu progreso.
*   **🔐 Autenticación y Seguridad**: Sistema de inicio de sesión seguro, registro de usuarios y recuperación de contraseña.
*   **☁️ Sincronización en la Nube y Local**: Tus datos se guardan de forma offline en tu navegador mediante `localStorage` y se sincronizan en tiempo real con la nube a través de Firebase Firestore.
*   **⚙️ Ajustes Personalizados**: Modo oscuro/claro y herramientas para importar, exportar o restablecer tus datos localmente.

---

## 🛠️ Tecnologías Utilizadas

*   **React 18** (Renderizado reactivo y gestión de estados con reducers)
*   **Tailwind CSS** (Estilos premium y responsive en tiempo real)
*   **Material Symbols** (Iconografía limpia de Google)
*   **Firebase** (Autenticación y base de datos Firestore)
*   **Babel** (Compilación directa en navegador para máxima agilidad)

---

## 📦 Instalación y Uso Local

Al ser una aplicación web estática autónoma, no requiere instalación de dependencias ni compiladores:

1. Clona este repositorio o descarga el archivo `index.html`.
2. Abre `index.html` directamente en cualquier navegador moderno.
